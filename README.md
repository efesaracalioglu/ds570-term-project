# F1 Strategy — Pit Stop Prediction

An end-to-end data science pipeline that predicts Formula 1 pit stop decisions using race telemetry data, served via an interactive dashboard.

## Problem

In F1, pit stop timing is one of the most consequential strategic decisions a team makes. This project trains a classification model to predict whether a driver should pit on a given lap, based on tyre age, lap times, track position, and race context.

## Data

**Source:** [F1 Strategy Dataset — Pit Stop Prediction](https://www.kaggle.com/datasets/aadigupta1601/f1-strategy-dataset-pit-stop-prediction/data)
